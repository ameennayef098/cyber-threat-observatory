# مرصد التهديدات السيبراني

موقع إعلامي توعوي للأمن السيبراني للمعرض المدرسي، يحتوي على:
- لوحة تحكم
- خريطة التهديدات (ThreatFox C2)
- مكتبة التهديدات
- مختبر العمليات
- مسح OSINT
- اختبار تفاعلي
- Areas إعلامية

الملفات الرئيسية:
- index.html  — الصفحة الرئيسية
- assets/     — النصوص، الصور، ملفات جsvectormap، القواعد
- game.css / game.js — ألعاب التوعية

يمكن تشغيل الموقع مباشرة عبر `file://` أو خادم ثابت.
